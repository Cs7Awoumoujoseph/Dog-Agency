# TinDog — Landing page

## Présentation

TinDog est une page d'accueil promotionnelle inspirée des applications de rencontre pour chiens. Le projet met en pratique la création d'une interface responsive à l'aide de HTML, CSS et Bootstrap.

La page présente le service, ses avantages, des témoignages, des offres tarifaires et des boutons d'appel à l'action.

## Fonctionnalités et sections

- Section d'introduction avec titre et boutons de téléchargement illustratifs.
- Présentation de trois avantages du service.
- Témoignage client.
- Comparaison de formules tarifaires.
- Mise en page responsive grâce à Bootstrap.

> Il s'agit d'une maquette front-end : les boutons de téléchargement et les offres sont des éléments de démonstration, et ne constituent pas une application fonctionnelle de mise en relation.

## Technologies

- HTML5
- CSS
- Bootstrap 5.3.3 chargé depuis un CDN
- SVG pour les icônes

## Lancer le projet

Aucune compilation n'est nécessaire.

1. Clonez le dépôt :

   ```bash
   git clone https://github.com/Cs7Awoumoujoseph/Dog-Agency.git
   cd Dog-Agency
   ```

2. Ouvrez `index.html` dans un navigateur.

Pour un environnement de développement, vous pouvez utiliser l'extension **Live Server** de Visual Studio Code.

## Personnalisation

- Modifiez le contenu et les sections dans `index.html`.
- Adaptez les styles dans le dossier `css/`.
- Remplacez les images de démonstration par vos propres ressources.
- Mettez à jour les prix et les textes si la page est réutilisée pour un autre projet.

## Améliorations possibles

- Traduire l'interface en français.
- Corriger les textes et uniformiser le nom du projet.
- Vérifier que toutes les images référencées existent et utiliser des chemins relatifs cohérents.
- Relier les boutons à de vraies pages ou destinations.
- Ajouter une vérification d'accessibilité et tester l'affichage sur mobile.
